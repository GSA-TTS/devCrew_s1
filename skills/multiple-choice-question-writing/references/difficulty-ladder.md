# Difficulty ladder for multiple-choice items

Difficulty is raised by changing the cognitive demand, the richness of the context and the sophistication of the distractors, not by obscure wording.

## Levels

| Difficulty | Bloom levels | What the item asks | Verbs the stem must require |
|---|---|---|---|
| Easy | Remember, Understand (knowledge, comprehension) | Recall a definition, explain a concept | define, identify, recall, explain |
| Medium | Apply, Analyze | Use the concept in a scenario, break information into components | apply, analyze, compare, differentiate |
| Hard | Evaluate, Create (evaluation, synthesis) | Judge effectiveness, weigh trade-offs, choose a novel solution | evaluate, justify, design, synthesize |

A hard item presents a complex scenario in which several factors interact and no option is obviously correct, yet exactly one option is defensibly best.

## Deconstruct the stem first

1. List the core knowledge components of the stem (terms, parts, steps, rules).
2. List the relationships between them (sequence, cause and effect, dependency).
3. Name the underlying principle that makes the correct answer correct.
4. For each difficulty, write what recall, application, analysis and evaluation of this content would look like.

## Techniques for medium items

- Application scenario: embed the core knowledge in a realistic situation that needs contextual reasoning, so the student applies the concept instead of reciting it.
- Multi-concept integration: require the relationship between two or more knowledge items, or between this concept and a related one, so more than one fact is needed.
- Partial context: give part of a process or worked case (for example the first two steps) and ask for the missing or next part that best fits.

## Techniques for hard items

- Conflicting requirements: set competing priorities and ask which option best resolves the trade-off.
- Minimal guidance: describe a novel problem without naming the concept that applies; the student must recognise which principle is relevant and transfer it.
- Abstract representation: give a diagram description, table, data set or code snippet with a subtle flaw and ask which flaw causes the failure.
- Multi-step chain: require several reasoning steps in sequence, such as tracing a root cause and then choosing the fix that addresses it rather than a symptom.

Keep the item multiple choice: where a hard scenario would invite "justify your choice", put the competing justifications into the options and the reasoning into the answer-key explanation.

## Calibration levers

Rigor aspects (adapt to any subject):

- Conceptual: understanding the principles.
- Procedural: carrying out the mechanics correctly.
- Application: adapting the concept to a novel context.

A medium item emphasises two aspects at moderate depth; a hard item integrates all three at depth.

Intrinsic load levers, each of which raises difficulty:

- Element interactivity: more concepts that must be held and connected at once.
- Novelty: a familiar concept in an unfamiliar representation or context.
- Problem space: more possible paths or solutions to consider.

## Level check for each item

Map the verb the stem actually requires to the table above. If a medium item can be answered by recall alone, or a hard item by application alone, rewrite it with one of the techniques for its level.
