# Contradiction classes and resolution rules

Use this file to fill the Class and Resolution columns of the contradiction register.

## Classes

Classify every material contradiction before trying to resolve it.

- Apparent: different wording for compatible facts.
- Temporal: both statements were true at different times.
- Definitional: the sources use different scopes or denominators.
- Jurisdictional: rules or outcomes differ by place.
- Identity: the sources refer to different entities with similar names.
- Version: different releases of a document, dataset, model or product.
- Measurement: methods, samples, units or uncertainty differ.
- Interpretive: the facts agree but causal or normative conclusions differ.
- Factual: the statements cannot both be true under the same conditions.

## Resolution rules

1. Normalize entity, date, unit, jurisdiction, version, definition and method.
2. Inspect the exact spans and methods of both sides.
3. Prefer the source closest to the event or to the controlling authority, subject to its integrity and method; compare methods, not reputation.
4. Seek one new independent primary route only if it could discriminate between the explanations and change the report.
5. Keep the losing evidence and the reason it was not selected.
6. If responsible sources genuinely disagree, report the disagreement, explain where it comes from, state what would resolve it, and calibrate the conclusion.
7. Do not average incompatible values or use a majority vote to settle a conflict.

Stop before the round limit when all remaining disagreement is interpretive or needs primary evidence that is unavailable. If a required high-impact conclusion depends on an irreconcilable factual conflict, do not state that conclusion; report the conflict instead.
