# Feedback templates

Use this file when writing the feedback for any item. Feedback explains the answer; a bare right or wrong mark leaves misconceptions in place. Write the template for an item type before writing its questions.

## Knowledge check, correct answer

1. Confirmation: a short statement that the answer is correct.
2. Why it is correct: the understanding the item required.
3. Deeper context: how the idea connects to broader concepts.
4. Forward look: why it matters for the next concepts or for professional practice.

A reference to the figure or section that shows the idea may close the feedback.

## Knowledge check, incorrect answer

Write one for each wrong option or each common wrong path.

1. Acknowledgement: a neutral not-quite, without shaming.
2. Likely confusion: the misconception that probably produced this answer.
3. Correct understanding: the right answer and why it is right.
4. Where to review: the chapter section (and figure, if any) that explains it.
5. Encouragement: a suggestion to reread that section, or a note that the next section will make it clearer.

## Vocabulary exercise

Give the correct term, the context that makes it the right one, and the section where it was introduced.

## Comprehension exercise, correct explanation

Name the specific understanding the answer shows, say where it will be used later in the book, and add one small extension the learner has not met yet.

## Comprehension exercise, incomplete explanation

1. Acknowledge what is on the right track.
2. Restate the learner's claim and ask why it holds.
3. Point to the section to review and list the key points it makes.
4. Ask a follow-up question that sends the learner back to try again.

## Exam-style item

State the correct option and the reasoning that leads to it, then give one line for each wrong option saying why it is wrong.

## Scaffolding by position

Early sections: corrective and scaffolded. Middle sections: moderate scaffolding. Late sections: minimal scaffolding, so the learner works out the approach. Chapter review: limited feedback, with peer discussion.

## Example (format only)

```text
Item: Which device forwards frames using MAC addresses?  Answer given: router

Not quite. Routers and switches both forward traffic, so the two are easy to
mix up. A switch forwards frames inside one network using MAC addresses; a
router forwards packets between networks using IP addresses. Section 5.1 and
Figure 5.3 compare the two. Reread that comparison before Section 5.2, which
builds on it.
```
