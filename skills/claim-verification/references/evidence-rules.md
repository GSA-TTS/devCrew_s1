# Evidence rules

Use this when answering a verification question and when filling the Evidence and Verdict cells.

## Source order

Prefer, in the order that suits the claim:

1. A direct computation, or the authoritative record for the fact (the official register, filing or database that holds it).
2. Primary official records, standards, specifications, filings, original papers, source code or direct datasets.
3. Independent high-quality secondary sources with a transparent method.
4. Curated reference sources.
5. General web pages, user-generated content and model-generated statements.

The order is not absolute: an official marketing page can be weaker than an independent test for a performance claim, and a superseded official page can be stale. Judge authority, independence, freshness, directness and scope separately.

## One search attempt

- Build the query from the standalone question, not from the draft's sentence. Keep entities, negation, dates, units, jurisdictions and quoted text.
- Rank relevance and authority separately: a high search rank is not authority.
- From each source used, take the exact passage that answers the question, with title, publisher or author, publication date where shown, and the date you read it.
- Check the passage against the claim for entailment, contradiction, units, dates and entity identity.
- An attempt gains only when it resolves the claim, adds a more authoritative or fresher source, adds an independent corroboration or settles a contradiction. Duplicate text and extra snippets gain nothing.
- If the question is still open, change one thing for the next attempt, chosen for the reason it failed: rewrite the query, split the question, try another source type, or widen the time window. Do not repeat an identical query.

## Support, not relevance

A passage supports a claim only when it entails the complete claim at the precision the claim states. A passage on the same topic is not support, similarity of wording is not entailment, and entailment does not show that the source is authoritative or current.

## No evidence versus failed search

Keep apart a claim that eligible sources do not resolve (Insufficient evidence) and a search that failed: a page that would not load, a blocked or paywalled source, an empty result set, or text that could not be read. Mark the second as retrieval failed in brackets after the verdict; it is not evidence that the claim is false.

## Conflicting sources

1. Confirm that the sources address the same entity, definition, period, jurisdiction, version, denominator and unit.
2. Prefer direct primary evidence for the proposition, but keep legitimate methodological disagreement visible.
3. Check publication and effective dates: a newer source may supersede an older one without showing the older one was wrong when written.
4. Look for independent corroboration rather than several pages copying one origin.
5. Record each position and its scope. Do not average incompatible facts.
6. If one source is authoritative for the question, use it and state that basis in the Evidence cell.
7. If the conflict still matters, add source conflict in brackets after the verdict and qualify the claim, or list it for human review. Do not pick a side for how fluently a source is written.

## Copied and planted sources

Several pages repeating one origin count as one source. Watch for a shared origin, coordinated wording, low-authority domains and inconsistent timestamps, and require independent origins before counting a source as corroboration.
